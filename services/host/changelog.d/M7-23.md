### Added

- Release chain of the host service (M7-23, docs/spec/18-release.md 6.3): `make release-build`
  now also writes the `.deb` and `.rpm` packages of `infra/host/linux`; `make release-apple` builds
  the signed and notarized `.pkg` per macOS architecture and `make release-windows` the signed
  MSI; `make trial-apple` runs the macOS chain with a test publisher. Every package installs the
  binary and the service definition of `bothy-host install`, owned by root, and starts, enables
  and pairs nothing.
- `bothy-host version` prints the version of the build (`VERSION` in a release).
- `internal/buildinfo.PackageKind` and `UpdatePath`: each package carries its kind, and on `4114`
  (or no common protocol version) the host service logs one line with the update route of that
  kind (`update_path`) before it exits `78` without a reconnect.

### Changed

- `make release-build` builds with `-buildvcs=false` and `-s -w` through
  `tools/distribution/hostdist.py`.
- `bothy-host install` on macOS enables the launchd job of the host service before it loads it,
  because the `.pkg` keeps it disabled until the service user exists.
