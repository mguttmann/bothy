### Fixed

- HD3 on macOS reports a passwordless sudo rule of the service user or of a session user again:
  the probe ran `sudo -n true` with an empty environment, and sudo found no `true` without a
  `secure_path`, so the check passed on every macOS host. It now runs `true` by absolute path.
- On Windows the host service reaches the helpers of its session users again: a helper wrote its
  answer while its next read was still waiting, which a synchronous pipe handle does one after the
  other, so the host service refused its start with `HD10 helper_unreachable`. The pipes of the
  local channel now use overlapped handles.
