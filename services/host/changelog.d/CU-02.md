### Added

- The computer helpers "Bothy Computer Helper" for macOS (Swift) and Windows (C++), the only
  processes that capture the screen and inject input for a computer session
  (docs/spec/27-computer-use.md 9, CU-02): the enablement switch with its generation, the
  indicator with a stop button, Esc at the real keyboard, the pause while the screen is locked
  and the release of every key on every end. They are not published; the owner signs them on the
  owner's own machines (D-CU-01-29) with `make helper-sign-macos` or `hostdist.py
  helper-sign-windows` and builds a host package with the helper as an optional component, which
  sets `host_service.computer_use` when selected.
- `host-platform.yml` builds and tests the helpers, installs the packages with and without the
  component and probes whether the hosted runners allow capture and input; native tests run
  where the probe passed.
