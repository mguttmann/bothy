### Security

- `golang.org/x/net` 0.60.0 to 0.62.0 (GO-2026-6860, GO-2026-6866) and `golang.org/x/crypto`
  0.57.0 to 0.58.0, the newest release; `go mod tidy` takes the indirect `golang.org/x/term`
  from 0.46.0 to 0.47.0. GO-2026-5932 (the `openpgp` packages of x/crypto) stays open: OSV names
  only an untagged commit after 0.58.0 as fixed, and no package of the module imports `openpgp`.
  The gate `osv` had let these findings pass because OSV-Scanner hides uncalled Go
  vulnerabilities when Go is installed (docs/quality/gates.md, section "Advisories").
