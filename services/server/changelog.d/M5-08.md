### Added

- App lock policy (M5-08, 08 9): `InstanceInfo` gains the required member `app_lock` with
  `required` from the new configuration key `security.app_lock_required` (default `false`) and
  `after_ms` from the new key `client.app_lock_after` (default `5m`, at least `1s`), for every
  authenticated caller. Both keys are process configuration; the server only delivers the policy.
