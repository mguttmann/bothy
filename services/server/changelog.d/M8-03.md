### Added

- Import interface of the server (M8-03, 22 5, 7, 8, 12.1, R-IM-04, R-IM-06): the operations
  `listImports`, `createImport`, `getImport`, `listImportItems`, `startImport`, `pauseImport`,
  `cancelImport`, `completeImport`, `setImportLead`, `applyImportBatch` and `setImportCursor` and
  the tables `import_sources` and `import_items` (with the deferred foreign key
  `messages.import_item_id`). Owners create a source with the mapping `import_source.discord.v1`,
  validated field by field, and drive its state machine with step-up and audit; batches of
  structure items (spaces, channels, forum tags, people) of a running source are one transaction
  per batch with origin keys, so a repeated or lost-answer batch creates nothing twice; unmapped
  and webhook authors become disabled placeholder people; new channels have no grant, no operator
  and are read-only while the source leads. `setImportLead` switches the lead and the read-only
  flag in one transaction and cancels the active runs of a channel that becomes read-only.
  `setImportCursor` stores the cursor and the tool counters; every change appends
  `import.progress`. `setChannelReadOnly` (`channel.read_only.set`) is enabled and refuses the
  channels an import lead controls. `import.apply` is a real owner requirement.
