### Added

- `Snapshot.active_threads` (M2-52, 04 6.3 item 4, R-SY-28): per visible channel the open threads
  of kind `thread` with an active run or unread for the caller, plus the threads active within the
  new key `sync.snapshot_thread_window` (default `7d`), newest first, up to the new key
  `sync.snapshot_threads_per_channel` (default `20`); pinned threads count toward the bound but are
  never left out. One statement over `threads_channel_state_activity_idx`, in `ready` and
  `getSnapshot` alike.
- `Channel.project_bound` (R-DM-54) in every channel read and channel event; creating or deleting a
  project binding raises `channels.version` and writes `channel.updated` in the same transaction,
  changing a binding and a readiness report do not.
