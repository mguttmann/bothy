### Added

- Forums for existing folders (M4-44): the heartbeat member `project_folders` carries the folder
  names a runner finds under its projects root (distinct, one segment of letters, digits, `.`,
  `_` and `-` that starts with a letter or digit, at most 255 characters); the server stores it as
  `agents.reported_project_folders` (migration 00084) when the list changed, and an absent member
  changes nothing. The new operation `listAgentProjectFolders`
  (`GET /api/v1/agents/{agent_id}/project-folders`, action `agent.project_folders.read`, owner
  only) answers the reported folders that no project binding names (compared without case) and
  `reported`, false while the runner never sent the list.
