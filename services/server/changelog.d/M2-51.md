### Added

- Run graph data (M2-51, 09 5.3, 5.5, 5.6, R-DM-53): one summary step per parent; a removed step
  is counted into the summary step of its own parent, and a finished step whose only child is its
  own summary step goes with it into the summary of its parent, so finished subtrees collapse
  upward and a long run with many finished subagents stays within `run.max_steps_persisted`.
  Summary steps stored before stay at the root.
- Stall marking (M2-51, 09 5.5): migration 00077 adds `runs.last_progress_at`, set by every
  successful `run.start` and every stored patch; `runs.stall_check` sets `stall_warned_at` of a
  `running` run without progress for `run.stall_after` (new key, default `10m`) with one version
  step and `run.updated` `add /stall_warned_at`; the next stored patch carries
  `remove /stall_warned_at`; a run in `waiting_input` is never marked. `stall_warned_at` is a
  member of `Run` and `RunSummary`, and `listActiveRuns` returns it.
- The metric `/metrics/progress_events` (`RunMetrics.progress_events`) is accepted in patches.
- The `focus` member `background_thread_ids` (04 6.2, R-SY-27): those threads get the run
  document once and `run.updated`, no `typing.started`, and they are not part of the presence
  focus (13 4.4, `gateway_presence`); both lists together count against
  `sync.max_focused_threads`.
