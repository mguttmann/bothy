### Added

- Terminal in the web console (M6-18, ADR 0070): `terminal.open` and `terminal.attach` from a
  console session pass only with a fresh, unconsumed passkey step-up whose stored WebAuthn session
  required `userVerification = required`; every other console step-up (password with TOTP, a new
  OIDC login, none, too old or consumed) answers `401 step_up_required` with reason
  `passkey_required`, and the quick reattach never applies in the console. identity reads the
  user verification fact from the challenge of the step-up (`actor.Actor.StepUpUserVerified`,
  `authz.FreshStepUpCheck.PasskeyRequired`). The terminal stream authenticates the console by
  the cookie of its upgrade: with the cookie the `Origin` must be the console origin (else `403`
  before the upgrade), `identify` carries no token and passes only for that console session and
  its device; any other `identify` without token and a token on a console connection close with
  `4004`.
