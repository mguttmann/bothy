### Added

- Command autocompletion (M2-17): `autocompleteCommand` (`command.autocomplete`, `rl.trigger`) and
  `answerAutocomplete` (`command.autocomplete.respond`, `rl.agent_runtime`), both without
  `Idempotency-Key`, and the gateway op `command.autocomplete_result`. The request is checked like
  `agent.invoke` without a run (trigger, I2, SR2, SR4, read-only and archived channels) and goes as
  the ephemeral `command.autocomplete_requested` with a fresh token (`trigger_kind = autocomplete`,
  no `run_id`) to exactly one live gateway connection of the owning agent; the first valid answer
  goes back to the person, and without one the person gets an empty list after
  `command.autocomplete_timeout` (AG-23). Without a live connection and in a forum channel without
  `thread_id` (R-AZ-26) the empty list comes at once; app commands answer `404` until M2-25. Late answers
  get `410 gone`, repeated ones `204`. Nothing is stored and no run is created. New configuration
  key `command.autocomplete_timeout` (below `http.request_timeout`, cross-check
  `autocomplete_below_request_timeout`); `command.autocomplete_max_choices` is capped by the
  `maxItems` of the answer schemas.
