### Added

- Backup service (M7-02): `bothy-backupd` runs `pg_full` and `pg_diff` (pgBackRest into repo1
  and, with `backup.offsite.target`, repo2), `logical` (`pg_dump -Fc` into restic) and `objects`
  (restic over the volume `files`, or a mirror without deletion for the driver `s3`) on the
  five-field cron schedules `backup.pg.full_schedule`, `backup.pg.diff_schedule`,
  `backup.logical.schedule` and `backup.objects.schedule` (UTC, at most one run per kind, missed
  times not caught up), and `expire` on repo1 only (`backup.pg.local_retention_full`). New
  commands `bothy-backupd backup <kind>` and `bothy-backupd expire --offsite --credentials DIR`
  (the owner's off-site expiry). Every run writes a row of the new table `backup_runs` through the
  port `status.BackupRuns` with the new role `bothy_backup` (secret `db_backup_password`, key
  `migrate.backup_password_ref`), which may write only that table; every successful run writes the
  manifest `backup_manifest.v1` into the row and as a restic snapshot next to the backup. The
  off-site target is an S3 bucket with versioning and Object Lock (`s3:https://...`, keys
  `backup.offsite.region` and `backup.offsite.use_path_style`, key files in `offsite/`), written
  only append-only, with a lifecycle rule for noncurrent versions that frees what the owner's
  expiry removed (backup-restore.md 2 and 9); an empty target backs up locally and warns "local backup only" in the start
  log and in `bothy config check`. Metrics `bothy.backup.last_success.timestamp`,
  `bothy.backup.wal.last_archived.timestamp`, `bothy.backup.duration`, `bothy.backup.size`,
  `bothy.storage.volume.free` and `bothy.storage.volume.size` with `service.name = bothy-backupd`.
  The image `bothy-postgres` adds restic 0.19.1, pinned by a SHA-256 per architecture.
- `bothy migrate up` refuses to apply pending migrations to an existing schema without a
  successful `pg_full`, `pg_diff` or `logical` run younger than `migrate.recent_backup_max_age`,
  as long as `migrate.require_recent_backup` holds; an empty database is exempt (M7-02, R-OP-13).
