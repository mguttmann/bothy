### Added

- Search load test (M3-16): `perf/search` (`TestPerf_Search`, build tag `perf`) measures
  `search.p95_target` on a synthetic German and English corpus of `search.benchmark_messages`
  messages with Zipf-distributed words and `search.prefix_p95_target` on the same world, against
  a server process with the default configuration on a durable database; it fails on a missed
  target and on any wrong answer (a leak, a rate limit, a timeout, a phrase or prefix without a
  hit). The same run records the time difference between a term only in unreadable channels and a
  term that occurs nowhere, the share of the search indexes in the database, and the rewrite of
  `messages.search_vector` with its index build per million messages. Library
  `perf/internal/searchbench`, seeding and product checks `perf/internal/searchworld` with
  small-corpus tests in `make test`; `perf/internal/report` reads the load test rows of chapters 02
  and 14, and `perfreport` takes `-required`.
