### Added

- Webhook transport for agents (V1-01; 09 section 4.2, 04 section 15.6):
  `createAgentWebhookSubscription` and `listAgentWebhookSubscriptions` are enabled. An owner with
  step-up subscribes an agent to any event type of webhooks.md section 7; the subscription has
  `agent_id` and is changed, paused, deleted and redelivered by id like an app subscription.
  `webhook_out.deliver` admits the agent itself; every attempt of an invocation-bearing event
  passes `runs.Delivery` and carries a fresh `invocation_token` (a retry with `redelivered`), a
  denied one is not sent and ends `dead` with `not_authorized`, and maintenance mode holds it in
  order.

### Changed

- The enable list `api/operations.yaml` is complete (V1-01, P-04): every `later` entry names a
  `reason` and the `feature` of 01 section 3 it belongs to, both required by the route
  generator; the gate check `TestEnableListComplete` admits only features that 01 lists as later,
  planned for V2 or V3. Today only the direct message operations of V3-01 wait.
