### Added

- The end-to-end test of computer use CU-T24 in `test/terminal/e2e/computer` (build tag
  `computere2e`): the owner switches the desktop on locally and writes a message, the runner's
  scripted agent lists, opens, clicks, types, zooms and checks pixels, a simulated lock pauses
  and resumes the session, `stopComputerSession` ends it; no key stays pressed and no byte of an
  image is in the database, the logs or the telemetry export of the server (CU-06).
- The terminal suite takes Debian packages for the host image (`suite.MainWith`,
  `stack.Options.HostPackages`, `stack.HostImageWith`).
