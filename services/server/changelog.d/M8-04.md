### Added

- Import tool `bothy import discord` (M8-04, 22 4 to 11, 14, 16, 19, ADR 0043): a dry run by
  default that sends only `GET` to Discord and Bothy and writes no file, `--apply` into the running
  source the owner started in the web console, `init-map` and `status`. The run checks the mapping
  file strictly, runs the preflight of 22 4.4 (bot token, readable channels, the
  `MESSAGE_CONTENT` probe, an active owner, mapped people and agents, name collisions), writes
  spaces, channels, forum tags, people, threads, messages, pins and attachments in Discord order
  with origin keys, advances the cursor only after a successful batch and keeps a run lease
  (`--takeover`). `--channel` and `--only-thread` narrow a run; an unknown ID ends it before any
  write. The check report (text or JSON) carries counts and structure names only, never content,
  file names, names of people, tokens or signed links. Exit codes follow 22 10.3; the tool's own
  configuration comes from `--config` and `BOTHY_IMPORT__...`.
