### Added

- Text extraction of attached files (M3-15, 14 section 5, R-SU-07): `search` with type `files`
  now finds an attachment by the words inside it, ranked below hits in its name and transcript
  and under the same rights filter and candidate limit. When an attachment of a supported type
  becomes deliverable, the same transaction creates its row in the new table
  `file_text_extracts` (with the language of the instance) and inserts the job
  `files.extract_text`, which extracts the text with pure Go adapters: plain text, Markdown, CSV,
  JSON and source code (`builtin-text/1`), HTML (`builtin-html/1`, `golang.org/x/net/html`),
  DOCX, XLSX and PPTX (`builtin-ooxml/1`) and ODT, ODS and ODP (`builtin-odf/1`). Archives are
  opened only in memory within `search.extract.max_uncompressed_bytes` and
  `search.extract.max_archive_entries`; an XML part with a document type declaration ends
  `failed` with `xml_doctype` and nothing is fetched. The periodic job
  `files.extract_text_refresh` re-extracts rows of older extractor versions and keeps them
  findable meanwhile. The text is deleted together with the file.
- Configuration keys `search.extract.max_input_bytes`, `search.extract.max_text_bytes`,
  `search.extract.max_uncompressed_bytes`, `search.extract.max_archive_entries`,
  `search.extract.max_xml_depth`, `search.extract.timeout`, `search.extract.refresh_interval` and
  `search.extract.refresh_batch_size`.

### Changed

- The headline of a file hit reads the name, the transcript and the extracted text joined by line
  feeds, in the language of the extracted text.
