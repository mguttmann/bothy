### Added

- Binding of imported session references (M8-06, 22 9, R-IM-10, RK-75): `bothy import discord
  --sessions FILE` reads JSON lines `{"discord_thread", "agent", "external_session_ref"}` with the
  optional `cost_baseline_micros` and `currency`, checks the whole file before any write (exit `2`
  naming the line, never the reference), drops and counts a line whose agent is not the planned
  operator of the thread's channel, ignores lines of threads outside the run, and sends the
  accepted reference with the thread item as `earlier_session`. The server writes one earlier
  `agent_sessions` row per thread, agent and reference (`is_current = false`, `started = true`,
  `ended_at` = the batch time, `end_reason = import`, the baseline) through the new port
  `agents.ImportedSessions.CreateEarlier`, also for a thread an earlier run posted, and never
  after the thread has had a current session; the thread item answers `session` (`taken_over`,
  `already_present`, `dropped_late`) and `stats.server` counts `sessions_<outcome>`. The check
  report fills the column "Sessions" (`sessions_taken`, `sessions_present`, `sessions_discarded`,
  `sessions_late`). `AgentSession` and the session object of `agent.invocation` carry
  `cost_baseline_micros` and `currency` when the baseline is above 0.
