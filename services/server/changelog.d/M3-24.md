### Added

- Load test `perf/push_handoff` (M3-24): `make perf` measures `perf.push_handoff_p95`, the time from
  the commit of a mention to the `200` of Fake-APNs, under `perf.sustained_messages_per_s` with
  the default `rl.message`, on a durable database with the server in the test process, and fails
  when it exceeds the threshold or when any mention of the window did not give exactly one push per
  registration with the right IDs, a badge and no text. New: `apnstest.Request.AcceptedAt`,
  `harness.Options.APNsFake`, `DBCPUs` and `DBMemoryBytes`, the test overrides
  `wire.Deps.APNsEndpoints` and `APNsRootCAs` (unreachable from configuration), the open-loop
  scheduler `perfkit.Schedule` shared with `load_messages`, and the packages
  `perf/internal/pushhandoff` and `perf/internal/pushworld`.

### Changed

- The consumer `push` decides all recipients of one event under one rights version and one read
  of the thread structure, and reads the coalescing window of a recipient only when the decision
  reaches it (`domain.NeedsWindow`); before, it read both again for every reader of the channel and
  fell behind the sustained message load (M3-24).
