### Added

- `GET /api/v1/agent-templates` (`listAgentTemplates`, new action `agent.templates.read`, owner
  only, no step-up, not audited when allowed): the shipped agent templates, embedded in the
  server, and the private templates of the new key `agents.templates_dir` (default empty), each
  with its definition draft (chapter 26 7). The folder is read once at start; a private template
  whose slug a shipped one has, or that fails the layout, the schema or a rule of 26 4.3, is
  skipped and logged with `template_slug_taken` or `template_invalid`. Nothing changes for an
  installation that does not set the key.
