### Added

- Switch-over and revert per channel (M8-07, 22 13.3 and 13.4): `bothy import discord switch
  --guild ID --map FILE --channel ID --discord-locked` runs the last mirror round for the channel
  and the settle check; it ends with exit `2` before any call without `--discord-locked` (the
  owner's confirmation that the Discord channel is read-only), exit `2` for a channel that is not
  imported, not led by Discord or whose source is not running, and exit `1` with the counts per
  reason while messages are held back or were not copied; otherwise it prints the owner's steps 3
  and 4 for the web console. `bothy import discord revert --guild ID --channel ID` only reads and
  prints per Bothy thread the messages written in Bothy while it led, the total and the owner's
  steps of reverting. `status` shows per mapped channel the lead, the Bothy channel ID, its
  read-only state, whether its operator is the planned one, and flags a lead that disagrees with
  the read-only flag as inconsistent.
