### Added

- `bothy setup demo [--seed N] [--data DIR] [--api URL] [--exchange DIR] [--pace DURATION]` (M7-27,
  16 16): turns an empty instance into the demo with the made-up data set of `infra/demo`. The
  owner comes from the system action `instance.bootstrap` of `bootstrap-owner`; every other record
  goes through the public API in the sessions of the people of the data set (step-up with the
  device key), so it passes `authorize` and the audit. The seed drives the warm-up; an instance
  whose setup is complete gives exit `3` before any write; at the end the command prints a new
  enrollment code of the owner. With an exchange directory it hands the agent tokens to the demo
  agent and pairs and confirms the demo host.
- The test harness takes `Options.EmptyInstance` (no first owner) and `Server.NewSetup`.
