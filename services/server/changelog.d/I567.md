### Fixed

- `recoverRunWake` with `usage_limit` no longer creates a second wake-up for one outage: while a
  `usage_limit` wake-up of an outage of the run is pending it answers that one (issue 567).
- `recoverRunWake` for a run that ended `cancelled` or `completed` stores the wake-up `refused`
  with the new reason `run_not_failed`, so the thread gets the note and the person the
  notification instead of nothing; a run that has not ended still answers `run_not_ended`.
