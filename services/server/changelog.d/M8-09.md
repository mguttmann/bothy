### Fixed

- `bothy import discord --follow` and `--once` now stop on SIGINT and SIGTERM after the current
  batch, free the run lease and exit `0` (M8-09). Before, the binary passed no signal to the tool,
  so a stopped mirror died at once and kept the lease until `import.lease_stale_after`, and the
  full import or `switch` that the owner ran next ended with exit `3`.
