### Added

- `console.grafana_embed_url` (M6-17, 25 9.2, 19 5 rule 7, SEC-VZ-2): empty by default. When set,
  every console response's CSP gains `frame-src` with exactly the origin of the URL (scheme, host,
  port; no path, no wildcard); without it the policy keeps the bytes of M6-03. `frame-ancestors
  'none'` and `X-Frame-Options: DENY` stay. The start check `grafana_embed_url` refuses a value
  that is not `https`, has user information or is on the host of `server.public_url` (the same
  origin lifts the sandbox; another port of that host would get the console's cookie), naming the
  keys and never the value; `bothy config check` warns when the value is on another site (the
  registrable domain of the public suffix list, or another scheme).
- `InstanceInfo` gains the optional member `grafana_embed_url`: `getInstance` sets it only for
  owners (`stats.read` on the instance in filter mode, the filter of `telemetry_dashboard_url`)
  and only when the key is set.
