### Added

- APNs adapter with Fake-APNs (M3-20, 13 sections 5.1, 6.1, 7.1 and 11): `notify/adapters/apns`
  implements `PushProvider` for `provider = apns` over HTTP/2 to `api.push.apple.com` and
  `api.sandbox.push.apple.com`, only through the egress client with the new option
  `egress.Options.HTTP2` and the two Apple hosts as its targets. It signs one ES256 provider JWT
  per environment and `push.apns.jwt_refresh_interval` with the `.p8` key of
  `push.apns.private_key_ref`, read again at each creation; `403 ExpiredProviderToken` renews once,
  a configuration error pauses the environment for one interval with one probe after it. Payloads
  carry only the keys of 13 6.1 (IDs, numbers, fixed keys) and the badge, the badge sync is
  `{"aps":{"badge":<n>}}`, and every answer maps onto the result classes of M3-19. New
  configuration keys `push.ttl` and `push.apns.*` with the cross-check `push_apns_complete`; the
  loader refuses `push.apns.jwt_refresh_interval` outside 20 to 60 minutes. `internal/wire` builds
  the adapter only with APNs enabled in the roles `worker` and `all`, and `bothy config check
  --secrets` resolves the key only then. `apnstest` is Fake-APNs, an HTTP/2 server with TLS on
  loopback that verifies the JWT and records every request.
