### Added

- Telemetry link for owners (M6-06, 17 8): `InstanceInfo` gains the optional member
  `telemetry_dashboard_url`. `getInstance` sets it from the new configuration key
  `telemetry.dashboard_url` (empty by default) only when the caller holds `stats.read` on the
  instance, checked in filter mode, so a person who is no owner gets no member and no deny audit.
  The start check `telemetry_dashboard_url` requires an http or https URL with a host and without
  user information when the key is set.
