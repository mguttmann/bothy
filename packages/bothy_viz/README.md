# bothy_viz

Visualizations of the statistics (docs/spec/25-visualization.md 7): view models, the ports
`LiveFrameSource` and `StatsQuerySource`, the basic forms, the fixtures and the harness. The six
views follow in M6-12.

Kind: Flutter package, a member of the Dart workspace at the repository root
(`resolution: workspace`, `publish_to: none`).

## Dependencies

Allowed members (docs/spec/15-client-architecture.md, 3.1; `tools/arch-check/rules.yaml`):
`design_system`, `api_client`, `domain` (arrows of the diagram), and through them `l10n`, which the
package also names directly for its texts. Every other member is out of reach; `make arch` fails on
a dependency or an import of it. Further rules:

- never depends on `sync_engine` or `local_store`, directly or through another member (rule 6,
  `make arch`);
- no WebView, `HtmlElementView` or iframe in `lib/`, `harness/` or `test/`
  (`test/no_webview_test.dart`, the package part of VZ-T16);
- no native source (rule 4); no charting library: every form is a `CustomPainter`.

## Layout

| Path | Content |
|---|---|
| `lib/bothy_viz.dart` | the public library; every public symbol has a doc comment |
| `lib/src/model/` | view models from the generated types (`LiveTopologyModel`, `BackendModel`, `DeliveryModel`, `ExecutiveModel`, `TimelineModel`, `RunCardModel`, `LaneModel`, `SeriesModel`, `TrafficLightModel`, `MetricTileModel`, `BarModel`); a missing cost member is "not shown", never zero |
| `lib/src/sources/` | `LiveFrameSource` with the base `LiveFrameSourceBase` (stale after `viz.stale_after` on a `VizClock`, error events), `StatsQuerySource`, and `FixtureLiveFrameSource`, `FixtureStatsQuerySource`, `FakeVizClock` for tests and the harness |
| `lib/src/marks/` | `LaneMark`, `RunCardMark`, `AreaMark`, `BarMark`, `TrafficLightMark`, `MetricTileMark`; colors only from `color.viz.*`, the run state and the state roles; texts only from `l10n` |
| `lib/src/slo/` | `slo_catalog.g.dart` (generated by `tools/observability/sli_bounds.py`) and `slo_catalog.dart` (display names) |
| `lib/src/fixtures/` | `VizFixtures`: decodes a fixture with the generated serializers |
| `fixtures/` | JSON fixtures per schema and state ([README](fixtures/README.md)); also assets, so the harness reads them from the bundle |
| `harness/` | the harness app `bothy_viz_harness` ([README](harness/README.md)) |
| `test/` | unit, widget, semantics and golden tests (`test/goldens/ci/` on every host, `test/goldens/macos/` only on macOS) |

Run from the repository root: `make lint test coverage arch COMPONENTS=apps`. Regenerate the
goldens with `flutter test --update-goldens test/goldens` in this folder. The API pages come from
`make docs` ([Dart API reference](../../docs/reference/dart-api.md)).
