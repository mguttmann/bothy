### Added

- New project from the app on the desktop (M4-43, 01 6.9, R-PR-20): for an owner every space row
  has "+" ("New project in `space`") and the space menu the same entry. The dialog offers an
  empty project, a clone of an `https` repository, an existing folder under the runner's projects
  folder, and an idea; the name is suggested from the URL or the idea and stays editable, and the
  runner is the space's default operator unless another active agent is chosen. It creates the
  forum, assigns the runner when needed, binds the project with `provision`, waits until the
  runner reports the folder ready and, for an idea, posts the idea as the first chat (kept as the
  forum's new post draft until then). Every step shows its state; a failed step names its cause
  in one sentence (a taken name, a folder bound elsewhere, a cancelled confirmation, no
  connection, an existing folder, a failed clone and the other reasons of the runner) and "Try
  again" resumes there without creating anything twice. When the runner has not finished within
  `ui.new_project_wait`, the dialog says so and may be closed.
- Design system (M4-43): `DsSpaceRow.addLabel` and `onAdd`, the action "+" of a space row, shown
  on hover, on focus and always in the density `touch`.
- Configuration keys `ui.new_project_wait`, `ui.new_project_poll_interval` and
  `ui.new_project_name_max_chars`.
