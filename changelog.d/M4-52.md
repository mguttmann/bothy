### Added

- Status dots in the sidebar (M4-52, 01 6.17, R-PR-31): on macOS, Windows, iOS and Android a chat
  shows a small mark when its agent did something the person has not seen yet: green when a run
  finished, yellow when a run is working, blue when the agent waits for an answer or an approval,
  red when a run failed. Each state has its own shape (dot, ring, diamond, triangle), a tooltip and
  the state in the screen reader label. Opening the chat clears the mark; it comes back only with
  the next change. Seen follows the person to their other devices through the read state. A mark
  replaces the unread bar of its row. Forum and project rows show the most urgent new state of
  their chats; Settings, Appearance has the switch "Show status on projects" (on by default).
- The local database of the apps moves to schema version 13 (the seen marks of the status dots,
  kept on each device).
