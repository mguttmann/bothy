### Added

- "New agent" in the desktop app, the phone app and the web console: a template, the interview
  with the builder agent or an empty form lead to one editable preview, and visible steps with
  step-up create the built-in agent on a hosting runner, store its definition, set its class and
  billing and, when asked, create a channel with the agent as operator; "Try again" resumes and
  creates nothing twice, "Close" keeps what exists, and the agent list marks an agent without a
  definition as "Not set up" (A1-08).
- The fake server of the sync engine answers the built-in agent operations of the dialog
  (`createAgent` with `hosted_by`, `setAgentToolClass`, the definition, templates, the interview,
  `createChannel`, `setChannelOperator`) with the refusals that fix the step order (A1-08).

### Fixed

- The agent list of the console no longer fails the list tile assertion of debug builds on its
  colored background (A1-08).
