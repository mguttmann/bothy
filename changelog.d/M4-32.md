### Added

- Accessibility of the desktop app (M4-32): the checklist `docs/quality/accessibility-checklist.md`
  for VoiceOver on macOS and Narrator on Windows with automated evidence per screen and the
  manual pass before a release; semantics tests per screen with a shared audit
  (`dsSemanticsProblems`, `dsAccessibilityTests` in `package:design_system/testing.dart`); an
  integration test that compares the platform accessibility tree (macOS Accessibility, Windows UI
  Automation) with the semantics tree; a test that the checklist names only existing tests.
- `DsMenuItem`, `DsDropdownField` and `DsFocusRing` in the design system.

### Fixed

- Screen readers can press buttons with their own label (card buttons, Stop); menu entries are
  buttons and say which level is chosen; every control shows a visible focus ring; settings
  switches and drop-downs, the time zone fields and the levels of the notification tree have
  names; text fields no longer hide the controls around them from VoiceOver; names are no
  longer read twice (composer, waiting posts, file tiles); people, group and audit rows are
  buttons; the tray menu speaks the language the person chose.
