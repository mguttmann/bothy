### Added

- Push on iOS and macOS (M5-04): a Notification Service Extension for each Apple app, Swift
  without the Flutter engine, replaces the placeholder of a push with "<channel> · <thread title>"
  and "<sender>: <excerpt>" fetched from `GET /api/v1/push/preview` with the preview token and a
  DPoP proof of the device key within `client.push.fetch_timeout`; "Message not available" on
  `404`, the placeholder without network, after the timeout or with `notify.preview_mode = none`
  (then nothing is fetched). The shared Swift package `ClientKit` holds the shared keychain, the
  App Group state, the DPoP proofs (byte for byte the profile of the Dart client) and the preview
  fetch. The app asks for the notification permission when a thread is first opened after the
  login, registers the APNs token with `registerPush`, keeps the preview token only in the shared
  keychain, registers again on a new token, unregisters on logout, opens the thread at the message
  on a tap and submits the extension's display counters as client metrics. The localized push
  texts are generated from the ARB files (`make apple-strings`), and a check in
  `make apps-platform` fails when an extension links a Flutter framework.
