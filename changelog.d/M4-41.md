### Added

- New chat from the sidebar on the desktop (M4-41, 01 6.8 item 8, R-PR-18, D-SB-9): every forum
  row has "+" ("New chat in `forum`" in a project forum, "New post in `forum`" otherwise), the
  same entry in the forum's context menu, and Cmd+N (Ctrl+N) starts it in the forum of the
  focused or selected sidebar row (on a text channel it does nothing). It opens the new chat view
  in the content column without a dialog: the operator line, a title that is optional where an
  operator agent names the chat (09 12) and required otherwise, the tags and the composer with
  the focus; Esc leaves it. The text is the person's draft of a new post in the forum (03
  `drafts` with `thread_id` NULL, `putChannelDraft` through the outbox), so it survives a restart
  and appears on the other devices; the draft row "New chat" in italics heads the forum's group,
  a second "+" opens the same draft, and an empty draft is deleted when the person leaves.
  Sending creates the post with its first message through the outbox (`createThread` with
  `clear_draft`, an empty title stays `auto`), also offline; the row shows "Sending" or "Not
  sent", then the post row takes its place and its history opens. No git worktree is created
  for a new chat (D-SB-12).
- Design system (M4-41): `DsSidebarDraftRow` with the states draft, sending and not sent, and
  `DsComposer.sendEnabled`, which keeps sending off while a caller needs more than the text.
- Fake server of `sync_engine` (M4-41): `putChannelDraft`, `deleteChannelDraft`, forum posts
  without a title (`title_source` `auto`) and `clear_draft` on the first message of a post.

### Changed

- The "New post" dialog of the forum overview is replaced by the new chat view (M4-41): "New
  chat" and "New post" of the overview open it, and "Edit" of a refused post moves its title,
  tags and text back into it. The shortcut table of 01 7 names the forum Cmd+N uses.
