### Fixed

- A post in a project forum no longer fails silently. The dialog "New project" offers only agents
  that can serve a project as the runner, preselects the only one, and lets the runner upload
  reply files in the new forum. A project forum that is not ready shows the cause in its header
  with the action that fixes it (make the runner the operator, change the folder name, check
  again) and says when the runner is offline; a message that failed for it shows the cause next
  to its red X and offers "Trigger again" to its author (desktop and mobile).
