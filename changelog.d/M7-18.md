### Added

- Capacity load test (M7-18, docs/spec/16-operations.md 13): `make load-capacity` installs the full
  stack from the images of a release like the portability test, ramps people, gateway connections
  and the message rate in steps until a performance target is missed, and writes the report behind
  the capacity table (counter lock wait, database connections, gateway connections and memory,
  fan-out lag, ClamAV memory, the inputs of the disk space formula) with profile, commit and date.
  The capacity table of 16 13 now holds measured numbers.
- Capacity gate in `make perf` (M7-18): `perf/capacity` runs the scenario as one steady step at
  `perf.capacity_steady_messages_per_s` and fails below `perf.capacity_min_messages_per_s`.
