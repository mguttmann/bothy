### Added

- Terminal on the desktop (M4-36): the sidebar group "Hosts" below the spaces with every host
  the person sees, its connection, "disabled" and the count of own sessions; the terminal view
  of a host on the right (`/hosts/<id>`) with one tab per own session, "New session" with the
  host's profiles and, for `claude`, only the working folders of the person's own session user,
  the step-up through the step-up device key, the time left until
  `terminal.max_session_duration`, the shortcuts of the table "In the terminal" (Cmd on macOS,
  Ctrl+Shift on Windows; Ctrl+C, Ctrl+D, Ctrl+K, Alt and Esc reach the shell), the search in the
  scrollback and "Open hosts and terminal" (Cmd+Shift+T, Ctrl+Shift+T). Each stream has its own
  WebSocket whose `identify` carries the access token and a DPoP proof of the device; denials
  show the server's reason.
- Local store: schema version 4 with the table `host_key_pins`, migrated without loss and never
  cleaned; only the wipe deletes it.
- Sync engine: `hostEvents` with `host.updated`, `host.presence_changed`,
  `terminal_session.changed` and the `access.changed` entries of kind `host`, without content.
- Terminal view package: `TerminalController.adopt` for a session the server lists, the app's
  shortcuts in the pane, and the server's reason of a refused opening in the banner.
- Fake server (sync engine testing): the terminal sessions, the device stream relayed to an
  in-process host, and the host events.
- `make terminal-stack`: the app's terminal against the terminal stack with a host container.
