### Added

- Jira reference app `plugins/jira-app` (M2-50): Jira issue and comment events in a forum, one
  thread per issue, the signature method read from `X-Hub-Signature` with an allow list of
  `sha256`, `/issue` with a form that creates the issue, optional mirroring of replies; tested
  against a Fake-Jira API and, inside the default pytest run, against the real server through
  `sdkserver`. The Python SDK gains the module `bothy_sdk.webhooks` (the verifier of M2-30) and
  `bothy_sdk.testing.sign_webhook`. Chapter 11 sections 10.2, 11.2 and 16, the configuration
  reference and the threat model (T-PL-01, T-PL-02) describe it; a change under `sdk/python/`
  selects the plugins gates.
