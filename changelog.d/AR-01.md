### Added

- Specification of autonomous runs: wake-ups that continue a thread later (at a time, when the
  checks of a pull request finish, when a command succeeds), a handover of live turns at a restart
  of the Claude Code runner, recovery runs after lost background work, a wake-up at the reset of
  the account's usage window, and an end state on every run, with caps on autonomous inputs
  (09 5.8 and 18.19, ADR 0077, plan section 22 and the briefs AR-02 to AR-10). Nothing of it is
  built yet, and every new feature switch is off by default (AR-01).

### Changed

- The brief index checks and the configuration reference accept the stage `AR` next to the
  milestones and stage `A1` (AR-01).
