### Added

- iPhone app (M5-02): the iOS runner (iPhone only, iOS 15) with its name, bundle identifier, URL
  scheme, signing team and associated domain from the build branding; the phone shell with the
  tabs Spaces, Mentions, Running and Me, one navigation stack per tab built from the router's
  paths, the edge swipe back and deep links that open a thread at its message with the stack
  Spaces, channel, thread; the phone forms of Spaces, the post list, the history with the
  compact live box (Stop at the top right, the full box as a sheet), cards with stacked buttons,
  forms as sheets and selects in the system picker, the offline banner with the waiting entries,
  and the onboarding screens E1 to E7 filling the screen; the privacy cover while the app is not
  in front; login through `ASWebAuthenticationSession`, passkeys only with an associated domain;
  the gateway closes with `1000` in the background and resumes in the foreground; the database
  files get `NSFileProtectionComplete` before the first open. The phone integration tests run on
  an iOS simulator in `make apps-platform` on macOS.
