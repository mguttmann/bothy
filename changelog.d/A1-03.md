### Added

- API contract of hosted agents (A1-03): the operations `setAgentHost`, `listHostedAgents` and
  `issueHostedAgentToken`, the member `hosted_by` of `Agent` and `AgentCreate`, the heartbeat
  capability `hosts_agents` and the durable event `agent.hosting_changed`; the Dart client and
  the event catalogue know them, and the sync engine skips the event, which only runners receive.
