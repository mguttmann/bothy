### Added

- Markdown, text, log, JSON, YAML and CSV attachments open in a document viewer inside the app
  on macOS, Windows, iOS and Android instead of an external app. Markdown is rendered like
  messages (headings, lists, task lists, tables, code blocks, quotes, links and images of the
  same message), JSON is pretty-printed and a small CSV shows as a table. The toolbar switches
  to raw text, searches with highlights (Cmd+F or Ctrl+F), copies everything, saves the file and
  opens it in another app; long documents get a table of contents. Large files open quickly as
  raw text, and blocked files never open.
- Code blocks in messages and documents show syntax colors for common languages and diffs.
