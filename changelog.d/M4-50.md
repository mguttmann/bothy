### Added

- Free text selection in the history (M4-50, 01 6.15, R-PR-29): on macOS and Windows the text of
  a message can be selected with the mouse across its paragraphs, lists, quotes, tables and code
  blocks (drag, double click for a word, triple click for a paragraph or a line, shift and click
  to extend). Cmd+C (Ctrl+C) and "Copy" at the top of the message menu copy the selection as plain
  text with the structure of the message; a part of a code block copies exactly, without fences
  and without the line breaks of the display wrap. Links, the copy buttons, "Wrap lines" and
  "Show all" keep working. On iOS and Android the message menu has "Select text", which opens the
  message in a sheet with the system selection.
