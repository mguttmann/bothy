### Added

- Import page of the web console (M8-08, 01 3.7 "Import from Discord", web only): owners see the
  import sources with kind, state and progress, the counters of the server and of the import
  tool, the failed items and one row per mapped channel with its Discord ID, its Bothy channel,
  the lead, the read-only state and whether the operator is the planned one. They add a source
  from the YAML mapping file (converted to JSON in the browser, the server's errors shown at their
  place in the file), start, pause, cancel and complete it, hand the lead of a channel to Bothy
  (the confirmation names the Discord step and the `switch` command; then the planned operator
  with the I1 check and the guided switch) and back to Discord (then the offer to remove the
  operator). Every step asks the confirmation and the step-up, which the command-line tool can
  never give. Completion is offered only when Bothy leads in every imported channel and warns
  that a repeated import is no longer idempotent once the retention class `import` is deleted.
  The page reads the server again after each step, on refresh and when the tab becomes visible.
  `make console-e2e` runs these flows.
