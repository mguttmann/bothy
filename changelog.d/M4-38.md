### Added

- Terminal E2E and performance targets on the desktop (M4-38): `make e2e-desktop` and `make
  perf-desktop` gain a terminal part (`make e2e-desktop-terminal`, `make perf-desktop-terminal`)
  against the client stack of the terminal with a host container. In the E2E an owner pairs the
  host through the administration (the real `bothy-host pair` in the container), opens a shell
  with the step-up, runs a command, detaches, reattaches with the scrollback, exits with a code
  and ends the tab, and a typed canary is in none of the app's paths and none of the stack's
  logs. The performance level measures `client.perf.terminal_frame_to_paint_p95` and
  `client.perf.terminal_throughput_min` in a profile build against an output generator in the
  host service and fails when one is missed.
- Terminal view package: test-only timing hooks of the controller and the screen, compiled only
  with `--dart-define=TERMINAL_PERF_HOOKS=true`.
