### Added

- Showcase (M7-28): `make showcase PLATFORM=<platform>[,...]` (`tools/showcase/capture.py`) starts
  the demo instance of `make demo`, captures the apps inside the app through Flutter's image API
  (`apps/client/e2e_test/showcase`, both themes, on Android also the video of one flow), the web
  console and the Grafana panel plugin in headless Chromium, strips every file of its metadata and
  files it under `docs/assets/showcase/` with its manifest entry (script, commit, demo seed).
  `tools/showcase/showcase_cli.py check`, part of `make docs`, fails on a file missing from the
  manifest, a manifest entry without its file, another format and any metadata (PNG text, EXIF,
  time or ICC chunks; MP4 `udta`, `meta`, `uuid` boxes and creation times).
- Changelog summary check (`tools/ci/changelog_summary.py`, part of `make fragments-check`): every
  release section of every `CHANGELOG.md` starts with a `Summary: ` line for users; `make
  release-prep` writes a placeholder line that fails the check until it is replaced.
- Release page template `.github/release-template.md`, rendered by `tools/ci/release_notes.py` in
  the `publish` job of `release.yml`: the summary first, then what changed for users, upgrade
  notes, technical entries and verification; a section without a summary stops the release.
- Architecture graphics render in light and dark (`<name>.svg`, `<name>.dark.svg`); the docs site
  shows each in its colour scheme, and `make diagrams` fails when a text or line misses the
  contrast gate of the design tokens in either rendering.

### Changed

- The README and the docs landing page show the product with images of the demo instance, the
  one command of the setup wizard and a reading path.
- Cluster and tertiary borders of the diagrams use `color.border.control` for non-text contrast.

### Fixed

- TV mode of the live views (desktop app and web console) underlined every text with Flutter's
  yellow fallback style, because it is pushed as a page without a Material ancestor; it now has
  the theme's text style like every other page (found by the showcase of M7-28).
