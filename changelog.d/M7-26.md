### Added

- The Compose profile `observability` starts Grafana with the panel plugin `bothy-live-panel` and
  the dashboard `bothy-live`; the product bundle carries the plugin build from its release ZIP,
  and Grafana allows exactly this one unsigned plugin ID.
- `make ops-check` fails when the unsigned plugin setting of Grafana names anything but
  `bothy-live-panel` or stands anywhere else under `infra/`.
- The portability test checks VZ-T13 through Grafana's API: the plugin loaded unsigned, the
  dashboard `bothy-live` provisioned, and only this plugin named unsigned in Grafana's log.
- `make release-trial COMPONENT=grafana-bothy-live` and the release job `plugin-signing` for the
  component `grafana-bothy-live`.
