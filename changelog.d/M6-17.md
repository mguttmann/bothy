### Added

- Optional Grafana embedding in the web console (M6-17, 25 9.2, R-VZ-12, SEC-VZ-2): with
  `console.grafana_embed_url` set, owners see the page "Operations (Grafana)" with the dashboard
  in an iframe (`sandbox="allow-scripts allow-same-origin"`, `referrerpolicy="no-referrer"`), a
  note that the page follows the permissions of Grafana and a link to open it in a new tab. The
  console reads the URL from the new owner-only member `grafana_embed_url` of `getInstance`;
  without it there is no page.
- `make console-e2e` phase 1b: the console with the key set against a static test proxy on its
  own origin (`infra/compose/test/compose.console-e2e-grafana.yaml`): exactly one `frame-src`
  origin, the dashboard loads in the cross-origin isolated console without a violation, no
  referrer, cookie or authorization reaches the proxy, a frame of another origin is blocked, a
  person who is no owner gets no member, and `bothy config check` refuses the console's own
  origin. The test proxy runs on `grafana.localhost`, which the per-run certificate now names.
  Phase 1 checks that the console without the key has no `frame-src` and no page.
- `docs/operations/grafana-embedding.md`: the auth proxy in front of Grafana with the headers of
  25 9.2 item 3.
