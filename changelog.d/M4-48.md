### Added

- Copy single blocks of a message (M4-48, 01 6.12, R-PR-25): on macOS and Windows every code
  block and every quote block has a copy button at its top right ("Copy code", "Copy quote");
  on iOS and Android a tap on the block copies it, with "Copied" and a light haptic, and a long
  press on the message opens the message menu, whose "Copy text" copies the whole message. A
  code block copies its raw content byte for byte (indentation, tabs, Unicode, long lines; no
  fence, no language tag; only the final line break is dropped). A quote copies its text
  without the `>` markers and, on all four platforms, also as HTML, so a paste into a rich
  editor keeps its formatting. A block inside a quote copies only itself.
