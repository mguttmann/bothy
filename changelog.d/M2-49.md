### Added

- GitHub reference app `plugins/github-app` (M2-49): GitHub issue and pull request events in a
  forum, `/issue` with a form that creates the issue, optional mirroring of replies; tested
  against a Fake-GitHub API and, inside `npm test`, against the real server through
  `sdkserver`, whose protocol gains the TLS front `app_front` and the ops `app_backend`,
  `create_forum` and `call`. Chapter 11 sections 10.1 and 16, the configuration reference and
  the threat model (T-PL-02) describe it; `make bootstrap-ci` installs every tracked npm lock
  under `plugins/`, and a change of the server or the TypeScript SDK selects the plugins gates.
