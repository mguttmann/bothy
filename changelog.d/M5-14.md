### Added

- Run graph and control room on the phone (M5-14): the tab Running shows "Running now" as
  control room cards in one column at full width (M11) with the switch "Cards" and "List", the
  filters Space, Agent and "mine only" as a sheet, and Stop at full width where the server allows
  `run.cancel`; a tap on a card opens the run graph (M12) on the Running stack, and the button
  "Graph" of the live box sheet opens it on top of the thread. The run graph of `bothy_viz` gets a
  touch layout as a parameter of the same view (`RunGraphLayout.narrow`, chosen below the design
  token `DsLayout.overlayWidth`): in portrait a narrow time bar on one shared track below each
  label, in landscape the bars beside the labels on the full time axis; in density `touch` a tap
  on a row closes or opens it; Stop stands at full width at the bottom. The visible cards are live
  only while the app is in the foreground: their places in `background_thread_ids` are freed the
  moment the app goes to the background and requested again when it returns, and the run store
  fetches their documents anew. Android has the same screens with the top app bar and system
  back. Goldens of M11 and M12 in portrait and landscape and a fake server test on the phone.
