### Added

- Turns of built-in agents from their definition (26 5): before every turn the runner fetches the
  definition with the hosted token, checks it with its own copy of the rules (held equal to the
  server's by the corpus `tests/agent-definitions`), rebuilds the agent and control folders under
  `runner.hosted_agents_root` (every file written by the runner, foreign surfaces and symbolic
  links removed, other files kept), writes the per-turn MCP file with resolved secrets (mode
  `0600`, deleted after the turn, swept at start) and runs the turn in the agent folder with the
  command line of 26 5.3. A failing definition, or a `stdio` server under a token class below
  `host`, ends the run with `tool_class_mismatch` before `run.start`. Folders are also written
  when an agent connects and on `agent.definition_changed` (A1-05).
- The cost cap of a definition becomes `--max-budget-usd`; a run it stops ends `runtime_error`
  with the cause `cost_cap_reached`.
- Channel skills behind the new key `runner.channel_skills_dir` (default off), only in `host`
  turns of the runner's own agent and of hosted agents; below `host` the skipped references are
  named in the live box.
- New key `runner.mcp_stdio_runners`; `runner.hosted_agents_root` is now required with
  `runner.hosted_agents` and refused at start when it overlaps `runner.state_dir` or
  `runner.projects_root`, lies below a `CLAUDE.md` or is writable by group or others.
- Probe module `tests/real_cli/test_hosted_probe.py` for the points of 26 5.7.
