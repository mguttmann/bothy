### Added

- Computer use behind `runner.computer_use` (default off, docs/spec/27-computer-use.md 10): every
  turn under tool class `host` loads the MCP server `bothy-computer-mcp` (`runner.computer_mcp_bin`)
  through the per-turn file `<runner.state_dir>/turns/<run_id>.computer.mcp.json` (mode `0600`,
  removed at the end of the run and swept at start) with `--mcp-config` directly after
  `--permission-prompts none` in print mode and directly after the flags of the class in
  background mode, without `--strict-mcp-config`. The file names one server `bothy_computer` with
  the five variables `BOTHY_COMPUTER_DIR`, `BOTHY_COMPUTER_NONCE` (fresh per run),
  `BOTHY_COMPUTER_TIMEOUT_MS` (`runner.computer_request_timeout`), `BOTHY_COMPUTER_PINS` and
  `BOTHY_COMPUTER_SERVER` (`runner.server_url`).
- The request folder `<runner.state_dir>/computer-requests/<run_id>/` (27 10.2): the runner checks
  each request against the run's nonce and calls `computer.desktops.list` and `computer.open` with
  its agent token, DPoP proof and invocation token, which never reach the turn; the answers carry
  only the members of 27 12.2.
- The system prompt section `## Computer use` (27 10.3) in turns with the tool.
- The end of a computer run (27 10.5): after a run that opened a session, the background session
  is stopped and removed, and the transcript and the tool result files of the session are deleted
  from the CLI's configuration folder; a failure is logged as `computer_transcript_left` and named
  in the status line of the thread's next run, which tries again.
- The runner refuses to start with `runner.computer_use` unless `runner.computer_mcp_bin` is an
  absolute path of an existing regular file that neither group nor others may write.
- Fake-Claude calls the MCP tools of computer use with the scenario key `computer`
  (`tests/fake_claude/fake_computer.py`): it starts the server of the per-turn file of
  `--mcp-config` and runs a script of tool calls, marks and gates; the test against the
  `bothy-computer-mcp` of the tree is `tests/computer_mcp`.
- Probes of 27 16 against the real CLI (`tests/real_cli/test_computer_probe.py`, part of
  `make runner-real-cli`).

### Fixed

- The start, `stop --turns` and the hosted leftover check read only files `<run_id>.json` of the
  `turns` folder as turn records; another file there was logged as `turn_record_unreadable`.
