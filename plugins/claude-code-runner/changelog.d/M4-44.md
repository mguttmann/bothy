### Added

- Project folder report (M4-44, 09 18.13): every heartbeat carries `project_folders`, the names
  of the Git work trees directly under `runner.projects_root` (one-segment names only, no hidden
  or temporary clone folders, symbolic links only when they stay under the root), in code point
  order and at most `runner.project_folders_max`; a longer list is cut and logged as
  `project_folders_truncated`, an unreadable root sends the empty list and logs
  `project_folders_unreadable`. The app offers these folders to add a forum for each.
- Configuration key `runner.project_folders_max` (default 500, at least 1).
