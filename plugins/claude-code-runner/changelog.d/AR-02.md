### Fixed

- A restart or stop of the runner no longer leaves a running turn behind. Before, the stop
  removed the turn's record while Claude Code went on running without the runner, holding the
  chat's session until its background work ended. Now the runner stops each of its own turns as
  a stop by a person does (SIGINT, then SIGTERM and SIGKILL, each escalation logged with
  `stop_escalated`), finishes the run `cancelled` with the reason `adapter_stopped` and a note in
  the thread, and removes the turn's record only once no process of the turn is left. Turns it
  adopted after a crash keep running and are taken over by the next start, as before.
