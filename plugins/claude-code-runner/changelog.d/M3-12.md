### Added

- Answer attachments (M3-12, docs/spec/09-agents.md 18.10): `ATTACH: <path>` lines outside code
  blocks are removed from the answer; the files are checked (roots by name in
  `runner.attach_allowed_roots`, denied patterns in `runner.attach_denied_patterns` that always
  contain the list of 18.10, `realpath`, regular file, one link, not empty, the limits of
  `getInstance`), copied into private staging copies and uploaded one after the other through the
  upload session inside the run binding, then attached with `attachment_file_ids`. All or none:
  any rejection, failed upload or refused attachment sends the answer without attachments and
  with a notice of base names and closed reason codes. The progress of a set is persisted, so a
  runner that adopts the turn after a crash resumes it once; a stop cancels the upload and sends
  nothing. `/status_line` is `uploading_attachments` while a set uploads.
- The heartbeat reports `capabilities.files_out = true`.

### Changed

- `TMPDIR` of a turn is the run's own temporary directory `<runner.state_dir>/tmp/<run_id>`
  (mode `0700`, removed when the run ends); the retention sweep also covers `outgoing/` and
  `tmp/`. The runner prompt explains `ATTACH:` lines, and the live box excerpt never shows them.
