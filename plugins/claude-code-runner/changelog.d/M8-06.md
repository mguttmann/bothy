### Added

- Cost baseline of a bound session (M8-06): a session whose `AgentSession` carries
  `cost_baseline_micros` and for which the runner has no stored values books per run only the
  amount above the remaining baseline, shared across the models in proportion and never below
  zero; a reset of the runtime's counters clears it, a baseline in another currency than US
  dollars is ignored with a warning. Tokens are not reduced (no token baseline in the data model).
