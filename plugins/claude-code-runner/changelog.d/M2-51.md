### Added

- Run graph data from the stream (M2-51, 09 18.4, 5.6): a task step hangs under the step of the
  tool call its `tool_use_id` names (at the root without one); a task of type `local_workflow` is
  a step of kind `workflow`; the `usage` of `task_progress` and `task_notification` becomes the
  step detail member `usage` (`tokens`, `tool_uses`, `duration_ms`), never a cost.
- `tool_progress` counts into `/metrics/progress_events`, patched only when the last change of the
  turn is older than the new key `runner.progress_patch_interval` (default `2m`), so a long tool
  does not get the stall notice of the server.
- A recording of the stream fields of the pinned CLI 2.1.259 (`tests/fixtures/recording`), the
  Fake-Claude fixture `graph` and its scenarios; the level-one switch test checks the new fields.
