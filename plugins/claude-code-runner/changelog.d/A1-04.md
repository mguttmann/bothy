### Added

- Hosting of built-in agents behind `runner.hosted_agents` (default off, 26 3): the runner lists
  the agents it hosts at start, on `agent.hosting_changed`, on `agent.updated` and every
  `runner.channels_resync_interval`, fetches a token per agent with `issueHostedAgentToken` into
  memory only and renews it before it expires, and opens one connection, channel cache, heartbeat
  and state folder (`<runner.state_dir>/hosted/<agent_id>/`) per agent. A connection closed with
  `4012` drops the agent until the next list. The runner's heartbeat reports `hosts_agents` with
  `runner.hosted_max_tool_class`; a hosted heartbeat reports the lower of the agent's class and
  that ceiling. Slots of `runner.max_parallel_runs` are shared by every agent of the process.
  Until the runner runs definitions, a hosted run ends `failed` with `adapter_error` and the
  cause `definition_missing` (A1-04).
- New keys `runner.hosted_agents`, `runner.hosted_agents_root` (read only) and
  `runner.hosted_max_tool_class`; `runner.hosted_agents` needs `runner.dpop_key_ref`.
- Byte-equal fixtures of the command line, the heartbeats and the served channels of the runner
  without these keys (BA-T20).
