### Security

- The own check of a hosted agent's definition refuses `${` in an MCP `url`, `args[]` entry or
  plain header or environment `value` (`invalid`): the CLI substitutes `${VAR}` there from its
  own environment (26 4.2).
- A definition's `secret_ref` file is opened one name at a time below the agent's subfolder of
  `runner.hosted_secrets_dir` without following a link and must have exactly one hard link, so
  a hard link to a file elsewhere or a link swapped in after the check resolves nothing
  (26 5.1 item 3).
