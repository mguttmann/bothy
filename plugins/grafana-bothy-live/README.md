# grafana-bothy-live

Grafana panel plugin `bothy-live-panel` ("Live views" in the Grafana panel picker): the live views of the apps for
operations, from OpenTelemetry metrics in Prometheus only (level b of
[25-visualization.md](../../docs/spec/25-visualization.md), section 8). The plugin runs inside
Grafana, reads only the frames of Grafana's data sources and never talks to the server; metrics
carry no IDs (17 rule 9), so the views show agents and states, never channels or single runs.

Status: built (M7-25), in the Compose stack and released as a ZIP (M7-26), unsigned, not
published to the Grafana catalogue.

## Views

One panel shows one view; the option `view` selects it. The dashboard
[`bothy-live.json`](../../infra/observability/grafana/dashboards/bothy-live.json) has one panel
per view.

| View (`view`)                  | Shows                                                                          | Queries (`queries.yaml`)                                                                                                                                |
| ------------------------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Live topology (`topology`)     | lanes per agent: active runs by state, tool steps per minute, costs            | `bothy_run_active`, `bothy_run_steps_total`, `bothy_run_cost_total`                                                                                     |
| Backend view (`backend`)       | runs per billing mode, mode mismatches (I3), denials (I2), costs per mode      | `bothy_run_start_latency_seconds_count`, `bothy_agent_billing_mode_mismatch_total`, `bothy_agent_invocation_denied_total`, `bothy_run_cost_total`       |
| Delivery and sync (`delivery`) | p95 of delivery, connecting and catch-up, fan-out lag                          | `bothy_delivery_duration_seconds`, `bothy_gateway_connect_duration_seconds`, `bothy_gateway_catchup_duration_seconds`, `bothy_event_fanout_lag_seconds` |
| Executive page (`executive`)   | SLO traffic light with icon and text                                           | `slo:objective:ratio`, `slo:sli_error:ratio_rate30d`, `slo:period_error_budget_remaining:ratio`                                                         |
| Timeline (`timeline`)          | playback over the dashboard period (play, pause, jump, speeds 60x, 300x, 900x) | active runs, tool steps, delivery p95, lowest remaining budget                                                                                          |

Options: `warnBudgetRatio` (executive page, default 0.25: below it "budget tight") and
`showCosts` (topology and backend view, default on).

TV mode is Grafana's kiosk mode, not a mode of the plugin: open the dashboard with the URL
parameter `kiosk` (`/d/bothy-live?kiosk`), or use "Enable kiosk mode" in the user menu or the
shortcut `d k`; `Esc` leaves it. Verified for Grafana 13.2 (docs/DECISIONS.md D-M7-25-4). A
playlist started in a kiosk view mode rotates several dashboards.

## Design language

Colours, font families, sizes and radii come only from
[`design/build/ts/tokens.gen.ts`](../../design/build/ts/tokens.gen.ts) (generated by
`tools/design-tokens`, M7-24). `src/theme.ts` picks the light or dark token theme from Grafana's
theme. The fonts are the copies in `design/build/ts/fonts/`; the build puts them and their OFL
texts into `dist/fonts/`. The lint rule `bothy/no-color-literal`
([`eslint-rules/no-color-literal.cjs`](eslint-rules/no-color-literal.cjs)) rejects a hex
colour, a CSS colour function or a named colour anywhere in `src/`.

## Queries

[`queries.yaml`](queries.yaml) is the only source. `make generate` writes `src/queries.gen.ts`;
`make generate-check` fails when it is stale. `make signal-check` in the repository root checks
every metric and label in it against the signal catalogue
([signals.md](../../docs/observability/signals.md); 17 section 10 item 4), and a unit test holds
the targets of `bothy-live.json` equal to it.

## Development

```sh
npm ci                    # in this directory; root `make bootstrap-ci` does it too
make check                # generate-check, format-check, lint, typecheck, test
make build                # dist/ (unsigned)
```

The scaffold configuration in `.config/` stays as `@grafana/create-plugin` generated it; the
root files `eslint.config.mjs`, `jest.config.js`, `jest-setup.js`, `tsconfig.json` and
`webpack.config.ts` extend it. Dependencies are pinned exactly in `package.json` and locked in
`package-lock.json`; React, Emotion and `@grafana/*` are webpack externals that Grafana
provides, so the bundle holds only the plugin's own code, the token constants and the fonts.
The license and vulnerability exceptions of the build and test tools are in
[`osv-scanner.toml`](osv-scanner.toml), one entry per package with its reason.

A local Grafana for manual checks binds only `127.0.0.1` and needs
`GF_PLUGINS_ALLOW_LOADING_UNSIGNED_PLUGINS=bothy-live-panel`.

## Release and the Compose stack

```sh
make release-build VERSION=<x.y.z> OUT=<dir>   # npm ci, build, bothy-live-panel-<x.y.z>.zip
make stack-install                             # that ZIP of VERSION into the stack (checkout)
```

`release-build` packs `dist/` with
[`tools/ci/plugin_release.py`](../../tools/ci/plugin_release.py) into one top folder
`bothy-live-panel/`, reproducibly (sorted members, one fixed time and mode). The release of the
component (tag `grafana-bothy-live/v<version>`) adds the SPDX and CycloneDX SBOMs of the ZIP, its
cosign signature and the signed `SHA256SUMS` (job `plugin-signing` of `release.yml`);
`make release-trial COMPONENT=grafana-bothy-live` in the repository root runs the same steps
with a throwaway key. The product bundle carries the files of the same ZIP in
`infra/observability/grafana/plugins/bothy-live-panel/`, which `compose.yaml` mounts into
Grafana of the profile `observability`; `stack-install` puts them there in a checkout. Grafana
loads the plugin only because `GF_PLUGINS_ALLOW_LOADING_UNSIGNED_PLUGINS` names exactly
`bothy-live-panel`, and `make ops-check` rejects any other value (SEC-VZ-5). The portability
test checks the loaded plugin and the dashboard through Grafana's API (VZ-T13,
[25-visualization.md](../../docs/spec/25-visualization.md) section 8.3).
