### Added

  folder `bothy-live-panel/`) with SPDX and CycloneDX SBOMs, a cosign signature and the signed
  `SHA256SUMS`; the plugin stays unsigned for Grafana until V1.
- `make stack-install` puts the release ZIP of `VERSION` into the plugin folder of the Compose
  stack of a checkout.
