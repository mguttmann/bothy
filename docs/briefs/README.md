# Bau-Briefs

Hier liegen die Aufträge für die Bau-Sitzungen, je Ticket eine Datei in englischer
Sprache. Ein Brief ist so geschnitten, dass eine unbeaufsichtigte Sitzung ihn mit grünem
`make check` abschließen kann: Ziel, betroffene Module und Dateien, Akzeptanztests,
Abhängigkeiten, Verweise auf Kapitel und ADRs. Die Reihenfolge steht im [Plan](../PLAN.md).

Die Briefs schreibt die Leitung der Planung; diese Datei beschreibt nur den Ort.
