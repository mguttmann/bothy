# Bothy

**English.** Bothy (working name) is a self-hosted, open-source team chat that works like
Discord, in which AI agents are full participants: every thread can be an agent session
with a live view of the run, tool and status lines, questions and approval buttons, and
every person sees and controls only the areas shared with them. The project is in its
planning stage; this site holds the specification, the architecture decisions and the
guides. Most documents are in German with English identifiers. Start with the
[specification overview](SPEC.md), the [roadmap](roadmap.md) and
[CONTRIBUTING](https://github.com/OWNER/bothy/blob/main/CONTRIBUTING.md).

**Deutsch.** Bothy (Arbeitsname) ist ein selbst gehosteter, quelloffener Team-Chat im
Aufbau und in der Bedienung wie Discord, in dem KI-Agenten vollwertige Teilnehmer sind:
Jeder Thread kann eine Agenten-Sitzung sein, mit Live-Ansicht des Laufs, Werkzeug- und
Statuszeilen, Rückfragen und Freigabe-Knöpfen, und jede Person sieht und steuert nur die
Bereiche, die ihr freigegeben sind. Das Projekt ist in der Planung.
