# Bothy

**English.** Bothy (working name) is a command center for AI agents in chat form:
chat, live view, approvals, terminal, costs and statistics in one self-hosted,
open-source app. Agents such as Hermes Agent, Claude Code and others are full participants:
every thread can be an agent session with a live view of the run, tool and status lines,
questions and approval buttons; a terminal opens shells and coding-agent sessions on
connected machines, end-to-end encrypted; native views show what the agents do, what they
run on and what it costs. Every person sees and controls only what is shared with them.
The project is in its planning stage; this site holds the specification, the architecture
decisions and the guides. Most documents are in German with English identifiers. Start
with the [specification overview](SPEC.md), the [roadmap](roadmap.md) and
[CONTRIBUTING](https://github.com/OWNER/bothy/blob/main/CONTRIBUTING.md).

**Deutsch.** Bothy (Arbeitsname) ist eine Kommandozentrale für KI-Agenten in Chat-Form:
Chat, Live-Ansicht, Freigaben, Terminal, Kosten und Statistik in einer selbst gehosteten,
quelloffenen App. Agenten wie Hermes Agent, Claude Code und weitere sind vollwertige
Teilnehmer: Jeder Thread kann eine Agenten-Sitzung sein, mit Live-Ansicht des Laufs,
Werkzeug- und Statuszeilen, Rückfragen und Freigabe-Knöpfen; das Terminal öffnet Shells
und Sitzungen eines Coding-Agenten auf angebundenen Rechnern, Ende-zu-Ende verschlüsselt;
native Ansichten zeigen, was die Agenten tun, worauf sie laufen und was es kostet. Jede
Person sieht und steuert nur, was ihr freigegeben ist. Das Projekt ist in der Planung.
