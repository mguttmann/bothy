| AUD-PKG-P01/1 | 2026-11-23 | "Send again" after an `interrupted` or `stale` run sends with `clear_draft` false, so the draft of the thread stays. Attachments of the triggering message are not sent again; no REST read of a triggering message that is not stored was added. | The send cleared the draft the person had typed since, and a click that sent nothing gave no sign.
