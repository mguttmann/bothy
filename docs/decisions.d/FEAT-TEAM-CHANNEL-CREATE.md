# FEAT-TEAM-CHANNEL-CREATE Create a team channel from the space menu

| No | Date | Ruling | Reason |
|---|---|---|---|
| D-TEAM-CREATE-1 | 2026-11-22 | "Create team channel..." is shown when the person is an owner (`getMe`) and the stored access to the space has `manage`, the requirement of `channel.create` (05). It is offered on the desktop and the phone, like the team dialog (01 6.23). | The server refuses `enableChannelTeam` to anyone but an active owner and `createChannel` without `manage`; showing it only when both hold avoids an entry that can only fail. Before the space's access is reported the entry stays hidden. |
| D-TEAM-CREATE-2 | 2026-11-22 | The create goes through `TeamPort.createTextChannel` as an online call with one `Idempotency-Key` per name, like the other team operations (D-TEAM-APP-2), not through the outbox; a refused create drops its key, a lost answer keeps it. Cancel is disabled while a call runs. A channel created before a refused or lost switch is kept: the name field locks and the next press only calls `enableChannelTeam`. Cancel leaves such a channel as a plain text channel, which "Team channel..." of its menu can switch on later. | The dialog must show a refusal at once, and the next step (the team dialog) needs the new channel's ID. Deleting the channel after a refused switch would need `channel.delete` with step-up and could lose a message written meanwhile. |
| D-TEAM-CREATE-3 | 2026-11-22 | The team dialog opens by channel ID (`showTeamDialogOf`) for the new channel. | The sync may not have stored the new channel yet when the switch answers; the dialog needs only the ID. |
