# M6-17 Optional Grafana embedding in the console

| No | Date | Ruling | Reason |
|---|---|---|---|
| D-M6-17-1 | 2026-10-26 | One exact `frame-src` origin: `httpserver.FrameOrigin` derives it once at the start from `console.grafana_embed_url` (https only, a host, no user information, the host a DNS name or an IP literal, so no wildcard and no CSP delimiter such as `;` or `,` reaches the policy; the host in lower case, the port 443 dropped, an IPv6 host in brackets); `ContentSecurityPolicy(nonce, frameOrigin)` appends `frame-src <origin>` after the directives of M6-03 only when the origin is set, so without the key the bytes are those of M6-03 (`TestCSP_FrameSrcOnlyWithKey` compares them literally). Every console response carries it, the redirect of `/console` and a 404 below `/console/` included. The key is a string key with an empty default, because the schema allows an empty default only for string kinds (as `telemetry.dashboard_url`, D-M6-06-4); its chapter is 25. | Brief Design note 1; 19 5 rule 7; SEC-VZ-2. |
| D-M6-17-2 | 2026-10-26 | The same-origin rule is the start check `grafana_embed_url` (so the server start and `bothy config check` both refuse it), sharpened to the host: a value on the host of `server.public_url` (any port, any case, a trailing dot ignored) is an error naming both keys. The same origin would lift the sandbox (25 9.2 item 4), and another port of the same host would get the console's session cookie with every request of the iframe, because cookies are not separated by port (RFC 6265 section 8.5); 25 9.2 asks for Grafana's own subdomain anyway. The cross-site warning is printed by `bothy config check` only (`wire.GrafanaEmbedCrossSite` over `httpserver.SameSite`): another scheme, or another registrable domain by `golang.org/x/net/publicsuffix` (ICANN and private sections; the module register grants the new vendor group `xnetpsl` to `platform/httpserver` only, beside the other origin helpers there); a host without a registrable domain (an IP address, `localhost`, a public suffix itself) is its own site, never the last two labels. Limitation: the rule cannot know whether a browser sends the proxy's cookie in the iframe (third-party cookie rules differ per browser), so a foreign site is a warning, not an error. | Brief Design note 2; 25 9.2 item 4. |
| D-M6-17-3 | 2026-10-26 | Owner-only member and page: `getInstance` fills `grafana_embed_url` through the filter of `telemetry_dashboard_url` (`stats.read` on the instance, filter mode, no deny audit; `Admin.ownerOnly` serves both). The console reads `getInstance` once per signed-in person (`ConsoleAdmin.grafanaEmbedUrl`, only an https URL) and adds `ConsolePage.grafana` (`/console/grafana`) to the end of the navigation only when the member is present (`consoleNavigationFor`); the path without the member shows "No Grafana dashboard is set up for this console." and embeds nothing. The iframe is `HtmlElementView.fromTagName('iframe')` with `package:web`; `sandbox` and `referrerpolicy` are set before `src`, so the first navigation is already sandboxed. `allow-same-origin` keeps Grafana in its own origin; on another host of the same site it cannot reach the console through `document.domain`, because the cross-origin isolated console (COOP and COEP, SEC-HDR-3) has `document.domain` disabled. | Brief Design note 3; 25 9.2 items 5 and 6. |
| D-M6-17-4 | 2026-10-26 | A static test proxy instead of a real Grafana: phase 1b of `make console-e2e` runs Caddy (the pinned image of the TLS sidecar) in the network namespace of `api` with the per-run leaf on `https://grafana.localhost:9444` (the embed origin) and `https://localhost:9445` (an origin the CSP does not name), serving a static test dashboard with the headers of 25 9.2 item 3 and a JSON access log. The console stays at `https://localhost:8443` (its passkeys and the other phases depend on it); the embed host is a name of its own below `localhost`, which Chromium resolves to loopback without a host resolver rule, and the leaf names it, because on another port of `localhost` the console's cookie would reach the proxy (D-M6-17-2). `localhost` and `grafana.localhost` are two sites, so the configured value draws the cross-site warning and item 4 (same site) is not exercised in the browser; the config check test covers it. A person who is no owner is checked through `getInstance` of a device enrolled with the page's DPoP key (Robin), because the console's page decision rests only on that member; the page itself without the member is proven by the widget tests. | Brief Design note 4; Out of scope: no real Grafana in the product's Compose stack. |
