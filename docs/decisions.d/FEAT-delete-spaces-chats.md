# FEAT-delete-spaces-chats Deleting spaces, channels, projects and chats

Owner request of 2026-11-01. Design note: [delete.md](../design/delete.md). Normative text: 01 6.18,
R-PR-33; 03 `spaces`, `channels`, `threads`, `project_bindings`, R-DM-57; 05 `space.delete`,
`space.restore`, `channel.delete`, `channel.restore`, `channel.project.trash`, `thread.delete`,
`thread.restore`; 07 4.5a; 09 18.15, R-AG-38; 20 4.2a.
