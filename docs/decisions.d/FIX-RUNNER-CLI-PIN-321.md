# FIX-RUNNER-CLI-PIN-321 Claude Code pin 2.1.321, recordings by a program

A host with Claude Code 2.1.321 reports `degraded` with `runtime_version_untested` while the pin
is 2.1.288. The pin moves as design note 15 of M2-34 and D-RUNNER-CLI-PIN-1 ask: recordings
written again by the new CLI, the stream field table read again, level one of the real-CLI
suite. Normative text: 09 18.2, 18.4, 18.9 and 18.19.12, 26 5.

Everything below ran with the CLI from the npm package of the platform
(`@anthropic-ai/claude-code-darwin-arm64` 2.1.321, checksum compared with the registry) in a
temporary folder, with an empty `HOME`, its own `CLAUDE_CONFIG_DIR` and the local stand-in for
the API on loopback: no login, no credential, no model call.
