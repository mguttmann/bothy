# FLAKE-WIRE-ACK Every 5xx request failure names the types of its error chain

| No | Date | Ruling | Reason |
|---|---|---|---|
| FWA/1 | 2026-11-09 | Every `request failed` log record of a 5xx carries the Go types of the error chain as `exception.type` (outer first, joined by ` < `, never the error text), also for an error with a kind (`errs.Error`): an `internal_error` of an adapter, the 503 `unavailable` (cause `deadline_exceeded`) of the pool for a caller context that ran out, an `internal_error` at the request deadline. #599 added the types only for a socket deadline outside `errs`. | The flake `TestAgentConsumers/TestConsumerShutdownFlushesAck` (issue #238, runs 40158843382, 40159931690 and 41937873948) never failed at its acknowledgement: each time a setup call of the world failed, the last one `POST .../channels` with 503 `unavailable` (cause `deadline_exceeded`) 0.73s into the subtest. The same signature (500 `internal_error` without SQLSTATE or 503 `unavailable` (cause `deadline_exceeded`) on the first REST call of a subtest) hit `TestPollRetentionGivesGone` (42125117645), `TestLiveBoxPatchContentNeverLogged` (42389771140) and `TestRunnerTokenRevocationCloses4012` (42503057625), each within a second after a consumer of the same process logged a failed page while its gateway connection closed. The 503 record of 41937873948 can also come from the `errs` paths (`pg.Pool` maps an expired caller context to `deadline_exceeded`), which logged no source before this change. Not reproduced locally: 24 runs of `TestAgentConsumers` with `-race` at `GOMAXPROCS` 2, 4 and 8 on a host at load 30 to 40, and 660 connection teardowns each followed at once by four concurrent `POST .../channels` (all 201) found no failure, so no fix is made; the next occurrence names its error chain. Tests: `TestServerError_KindErrorLogsItsSource`, `TestServerError_PlainErrorLogsItsChain` and `TestDeadline_ExceededGives503` (each red before the change). |
