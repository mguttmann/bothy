| D-M2-13-3 | 2026-10-21 | Classification: origin decides before the author (`system` gives `other`/`system`; `import` and `app` give `other`/`unverified`; `agent` gives `assistant`/`self` for the run's agent, otherwise `other`/`unverified`; `human` gives `user` with `trigger`, `authorized` or `unverified`). | D-M2-13-4 | 2026-10-21 | Only own runs in `queued`, `running` or `waiting_input` have a context; any other state answers the same `404` as an unknown run. `queued` is readable because the adapter reads the context before `startRun`. | 05 4.10 "own active runs"; 04 15.3 point 4; AZ-P4. |
| D-M2-13-5 | 2026-10-21 | Session mode, floor and own messages: the mode is `DecideSession` of M2-12 over the session row of the run (`runs.agent_session_id`, read through `agents.RunSessions`; zero is no session) when it belongs to the run's agent, so a reset or bind during the run (09 9.4) does not change the mode the invocation announced (red team M1), with "used" meaning a started run of the agent in that session queued before this run. `new`, `bind` and guest runs have floor zero, include the agent's own messages and want `channel_context`; `resume` leaves the own messages out, has no `channel_context`, and its floor is the `thread_seq` of the triggering message of the latest earlier started run that has one, zero when that message lies outside the thread (the parent of an auto thread). | Delivery and context use one rule; a `thread_seq` of the main thread is no floor inside the thread. |
| D-M2-13-6 | 2026-10-21 | `channel_context` exists only when the plan wants it, the thread has a parent message the agent may read, and the parent lies in the thread's current channel; the window is the parent's main thread before the parent, without the parent itself. After a move it is absent. | Content of a source channel must not reach the readers of the target (T-AI-01, SR9, 07 6). |
| D-M2-13-7 | 2026-10-21 | Tombstones are not selected into `thread_context` or `channel_context` and count towards no limit; the triggering message appears as stored (a deleted one with empty content). | The window's limit counts only what the agent can use. |
| D-M2-13-8 | 2026-10-21 | Byte accounting counts only `content_md` after the per-element cut at the longest valid UTF-8 prefix within `agent.context_message_max_bytes`; the budget `agent.context_max_bytes` keeps a contiguous newest suffix across `channel_context` then `thread_context`; the exclusion of tombstones and of the agent's own messages applies before `history_backfill_limit`. | AG-21 "from old to new"; the triggering message is never cut and never counted. |
| D-M2-13-9 | 2026-10-21 | `truncated_before_seq` refers to the run's thread: set when the window reported older selectable messages or the budget dropped thread elements, then the `thread_seq` of the oldest kept thread element, or of the triggering message when none is kept. | The adapter loads older messages of the thread with `thread.read`. |
| D-M2-13-10 | 2026-10-21 | `RunContextMessage.channel_id` (required) carries the channel of each element. | SEC-AI-1 lists the channel among the marks of every element. |
| D-M2-13-11 | 2026-10-21 | Optional members appear only when they apply (`truncated`, `already_delivered` only when true, `reply_to_message_id` only when set, `truncated_before_seq` only when set); `channel_context` is present, possibly empty, exactly when it is built; `attachments` is always present and stays empty until M3 fills attachments into messages. | ADR 0053; the messaging representation of this build has no attachments. |
| D-M2-13-12 | 2026-10-21 | A triggering message the agent cannot read, or one that is neither in the thread nor its parent, ends the request with the `404` of an unknown run; a run with `trigger_kind` other than `message` is `internal_error` (logged with run id and trigger kind only) until M2-15 and M2-16 define its context. | `run_context.v1` has no place for another trigger (spec gap); fail closed. |
| D-M2-13-13 | 2026-10-21 | A context read opens no unit of work and takes no lock; each request recomputes every part, trust included. | Trust at request time (ADR 0054 "Confirmation"). |
