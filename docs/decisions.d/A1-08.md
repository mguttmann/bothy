| D-A1-08-2 | 2026-11-07 | Entry points: on the desktop the agent list of the administration and the space menu; on the phone the space menu of the Spaces page (a long press on the space row); in the console the agent list. Each shows only with an offer: `listAgentTemplates` answers and an active agent reports `presence.hosts_agents`; both reach owners only, so the client holds no permission rule of its own. Any failure of the check hides the entry. | 01 6.20 item 1 and 26 8.1; 15 1 principle 1. |
| D-A1-08-3 | 2026-11-07 | Step texts: "Create the agent on <runner>", "Set the tool class to <class>", "Store the definition", "Set billing to Personal" (or "Organization" when it is undone), "Create the channel <name>", "Make the agent the operator of the channel"; each with its state waiting, running, finished or failed in words, and one sentence for a failed step (cancelled step-up, no answer, field errors, `tool_class_too_low`, `host_tool_class_ceiling` pointing to "Close" and "Change runner", `definition_needs_host`, `hosted_holder_mismatch`, a taken handle or channel name, `version_conflict`, otherwise the problem text). | 01 6.20 item 4, brief design note 3; the sentences name what the owner can do next. |
| D-A1-08-4 | 2026-11-07 | Preview layout on the phone: the same single column of sections as on the desktop (identity, instructions, skills, MCP servers, secrets, settings, hosting runner, channel), in a dialog that fills the screen with the steps above the preview once "Create" was pressed and the buttons at the bottom. | One layout keeps desktop, phone and console equal (requirement 16); the sections already stack. |
| D-A1-08-5 | 2026-11-07 | Done is a comparison, not a flag: a step is done when its target in the preview equals what the agent has (class, the current definition by content, billing mode and holder, channel, operator). | D-A1-08-6 | 2026-11-07 | Idempotency: `createAgent` and `createChannel` keep their `Idempotency-Key` (a UUIDv7) while their request (handle, name, description, runner; space and channel name) is unchanged and take a new one when it changed; the other steps are writes with `If-Match`. | Brief design note 3; a repeat of the same request is answered from the server's record, a changed request is a new one. |
| D-A1-08-7 | 2026-11-07 | Locks: name, handle, description and the hosting runner are read-only once `agent.create` succeeded; the channel fields once the channel exists.
