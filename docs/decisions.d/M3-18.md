| D-M3-18-1 | 2026-10-15 | A preference write and delete resolve the target with `chat.Structure.LockNotificationPath`, which takes `FOR SHARE` on the thread row (kind `thread`), then the channel row, then the space row (when the channel has one), the order of `moveThread`, before `authorize(notification_pref.update)`.
