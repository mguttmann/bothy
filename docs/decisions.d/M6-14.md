| D-M6-14-5 | 2026-10-25 | The heartbeat decodes `rate_limit` in the agents domain: `state` from `ok`, `near_limit`, `limited`, `unknown`, `resets_at` optional and an RFC 3339 time, any other member refused; the stored JSON is exactly `{state, resets_at?}` with `resets_at` in UTC milliseconds. `resets_at` has no window bound: the server only shows it, and a provider window lasts from a minute to a billing month.
