| D-M8-03-7 | 2026-10-21 | The import creates through ports, never through SQL of another module. The stored mapping decides: a category or channel not named in it is `target_outside_source`, one mapped to `skip` is stored `skipped` (also a channel whose category is skipped, and one without category while `uncategorized_space` is `skip`); a new space or channel takes the name of the mapping, not of the item data; an `existing` target is adopted only when the item names exactly it. A new name equal to a live space (globally) or channel (in its space) is `409 conflict` `name_collision`. New channels get operator mode `none` (no inheritance of a space default), no grant and `read_only = (lead = discord)`; text channels get their main thread in the search language of the instance. `sort_key` of a new space or channel is a fractional index key the tool derives from the Discord position; another value is `400 validation_failed` at `/items/<i>/data/sort_key`. An adopted object keeps its name and position. | Design note 7, 22 5.1 rules 1 to 4, 14 3.1. |
