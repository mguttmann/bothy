# A1-01 Specification of the built-in agents

Owner request of 2026-11-05: an agent that lives in Bothy, created through an interview or from
strictly anonymous templates, running on local Claude through the Claude Code runner, only Claude,
additive and off by default, and the rest of V1. Design note:
[builtin-agents.md](../design/builtin-agents.md). Decision:
[ADR 0076](../adr/0076-built-in-agents-hosted-by-the-claude-code-runner.md). Normative:
[26-builtin-agents.md](../spec/26-builtin-agents.md), 07 2.13, 09 2.2 and 18.18, 10 10.3, 01 6.20,
03 `agents.hosted_by` and `agent_definitions`; plan: [PLAN](../PLAN.md) sections 15 and 21.
