# FIX-auto-title-overwrites-agent-title An automatic title never replaces a title set on purpose

| No | Date | Ruling | Reason |
|---|---|---|---|
| FIX-AT/1 | 2026-11-02 | `setThreadTitle` gets the optional member `auto` (default `false`). A title with `auto = true` is an automatic one: the server first applies the source rules as before (the operator agent on a `manual` title gets `409 title_manual`), then lets it fill the thread only while `title_source = auto` and the current title is empty or a placeholder (`thread.placeholder_titles`, 09 section 12 point 2); otherwise it answers `200` with the thread unchanged, without a new version or event. Package `title` decides this (`Placeholders.Fillable`). | Cause, read from an instance in operation: a forum post of the operator agent carried a status title set by its thread action (user agent `hermes-adapter-thread`); the owner's answer started a run in a new Hermes session, and after it the adapter's handler (`handler.py` `_set_title`, called from `_end_turn` when `session_mode == "new"`) put the Hermes session title, which Hermes takes from the first message (here a one-word reply), with `setThreadTitle` (user agent `hermes-adapter`). The server could not tell this automatic suggestion from the agent's deliberate title, because both come from the operator agent with `title_source = auto`. |
| FIX-AT/2 | 2026-11-02 | No new `title_source` value. A title the agent sets on purpose is recognised by its content (not empty, not a placeholder), the deliberate request by the absence of `auto`. `manual` stays the source of a person's title, and the operator agent still never replaces it. | The request already says what kind of title it is, so a new source would only add a migration and an enum change in every client without closing a further case. The only case it would add, an agent that deliberately sets a placeholder word as its title, has no known use. |
| FIX-AT/3 | 2026-11-02 | Both reference adapters send their automatic titles with `auto = true`: the Hermes adapter after the first completed run of a new session, the Claude Code runner for its `TITLE:` line. The Hermes thread action (`thread title`) sends without `auto` and keeps replacing its own status title. The SDK's FakeServer applies the same rule with the default placeholder words. | The two places that title a thread on their own are the class; the thread action is the deliberate path. |
