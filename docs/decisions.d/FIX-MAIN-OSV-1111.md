# FIX-MAIN-OSV-1111 Advisory gate red on main after new advisories

`make osv` failed on main in run 43028486729 (push of 575359bdc, 2026-11-11) and before that in
the daily advisory run 42965017488 on the commit before it. No change of the repository caused
it: four advisories for node-forge were published on 2026-11-10 and one for the Go standard
library on 2026-11-11. The logs show only the first cause, because the target stops at the
OSV-Scanner step and govulncheck runs after it.
