| D-M6-16-1 | 2026-10-25 | `StatsSubscription` of `sync_engine` (`GatewayConnection.stats`, `SyncEngine.stats`) keeps the wanted subscription (none, the instance or one space) and the one the server holds as far as the client knows. `subscribe` and `unsubscribe` send at once on the identified connection, else after the next session start; after `ready` (a new gateway session after `identify`) the server holds none, so the wanted one is sent again; after `resumed` the server restored its own (04 6.3), so only a change made while disconnected is sent.
