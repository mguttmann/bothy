# FIX-RUNNER-CLI-PIN-325 Claude Code pin 2.1.325

The pin of the claude-code-runner moves from 2.1.321 to 2.1.325, the newest release of Claude
Code (https://registry.npmjs.org/@anthropic-ai/claude-code/2.1.325, retrieved 2026-11-16), as
the section "Changing the pinned version" of the runner README and D-RUNNER-CLI-PIN-1 ask:
recordings written again by the new CLI, the stream field table and the findings read again,
level one of the real-CLI suite. Normative text: 09 18.2, 18.4, 18.7, 18.9 and 18.19.12, 26
4.2, 4.3 and 5.

Everything below ran with the CLI from the npm package of the platform
(`@anthropic-ai/claude-code-darwin-arm64` 2.1.325; the checksum of the package compared with the
registry and the program compared with the one in the package) in a temporary folder that has no
`CLAUDE.md` and no `.claude` above it, with an empty `HOME`, its own `CLAUDE_CONFIG_DIR`, the
CLI's automatic update switched off and the local stand-in for the API on loopback: no login, no
credential, no model call. 2.1.321 was read and run the same way wherever a ruling compares the
two. "Read" means the CLI's file: the member lists of every message schema with a literal
`type`, and the code behind a finding, held against the same place of the 2.1.321 file. "Run"
means a turn against the stand-in.
