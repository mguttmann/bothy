# FIX-SECRET-ENV-REF Resolve the env:NAME secret of a template on the hosting runner

| No | Date | Ruling | Reason |
|---|---|---|---|
| D-FIX-SECRET-ENV-REF-1 | 2026-11-23 | The runner resolves `env:NAME` of a hosted agent's definition as the file `NAME` in `<runner.hosted_secrets_dir>/<agent_id>/`, through the same checks as a `file:` reference there (real path inside the agent's subfolder, no runner credential, opened without following a link, one hard link, mode `0600` or `0400`). It never reads the runner's environment for a definition; `NAME` is the name rule of the template and definition check (`[A-Z_][A-Z0-9_]*`), so it holds no separator and no `..`. The template form `env:NAME` stays as it is (issue 1425, 26 4.2 and 7.1). | Templates, the builder prompt and the server's template rule all write `env:NAME`, so one runner rule fixes every template without a conversion on the server, which never knows the runner's folder. Reading the runner's environment would let a definition send the runner's own variables to a URL of the owner's choice (red team of A1-05). |
| D-FIX-SECRET-ENV-REF-2 | 2026-11-23 | The preview names the storage place with the configuration key and the placeholder `<agent ID>` (`<runner.hosted_secrets_dir>/<agent ID>/`), not the real path. | The preview runs before `agent.create`, so the agent ID does not exist yet, and the server does not know the runner's configured folder. |
| D-FIX-SECRET-ENV-REF-3 | 2026-11-23 | The chain from template to turn is held by the corpus fixture `tests/agent-definitions/valid/template-research-summarizer.json`: the server test `TestTheResearchSummarizerDraftIsTheCorpusFixture` holds it equal to the server's draft of the shipped template, both validators run it with the corpus, and the runner scenario `test_a_template_s_env_secret_resolves_from_the_agent_s_own_folder` runs it as a hosted turn. | The runner's test harness has no server and no YAML reader; a shared JSON fixture checked from both sides is the closest real artifact without a new end-to-end harness. |
