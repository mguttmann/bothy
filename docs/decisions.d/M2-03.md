| D-M2-03-1 | 2026-10-20 | Schema `project_runner_config.v1` is defined in 09 section 18.1 and as `ProjectRunnerConfig` in `docs/api/openapi.yaml`: a closed object with the optional members `model` (string, `minLength: 1`) and `allowed_tools` (array of strings with `minLength: 1`, `uniqueItems: true`). | D-M2-03-2 | 2026-10-20 | Configuration key `project.binding_text_max_chars` (Server, default `512`, minimum `1`, maximum `600`, chapter 09): the longest `workspace_ref`, `repository_url`, `default_branch`, `runner_config.model` and tool name in Unicode characters, read at request time; longer gives `too_long`. 512 characters of at most 4 bytes in UTF-8, also after `lower()`, stay below the PostgreSQL B-tree entry limit of the unique index on `lower(workspace_ref)`; the maximum keeps that true for every configured value, and an index error that still occurs answers `400 validation_failed` with `too_long` on `/workspace_ref` instead of `500`.
