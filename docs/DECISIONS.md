# Ruling log

Status: planning state M0. This document is the ruling log according to [ADR 0001](adr/0001-adrs-in-madr-format-decisions-as-ruling-log.md): decisions with
reason and location that do not have their own ADR or that an ADR only summarizes. Load-bearing
decisions are ADRs in the [ADR index](adr/README.md). Every chapter of the
specification lists its own decisions with numbers such as `R-AR-01` in the section
"Decisions of this chapter"; the source is there, the reference is here. Decisions that
concern only a particular installation (its accounts, names, hosts, repository paths) are
not here but in the private operations repository of that instance ([ADR 0002](adr/0002-two-repos-public-product-private-ops-repo.md)).

## Rules for this log

1. **IDs are stable.** An ID is never reassigned, never renumbered and never deleted. An
   outdated row stays in place and names "superseded by" or "Current state:" in the decision, with the
   new ID or location.
2. **Every row has a decision, a reason and a location.** The location is a link to file and section.
   `make linkcheck` checks files and anchors; a renamed section breaks the gate.
3. **The chapter wins.** If a row deviates from the chapter, the chapter applies (specification first,
   [PLAN 1](PLAN.md#1-principles) principle 3), and the row is adjusted in the same change.
4. **New entries.** Build tickets record their rulings in a file of their own,
   `docs/decisions.d/<ticket>.md` (section 10). A change to the specification needs an ADR or
   an entry in this log.
5. **Owner questions** are listed with their default in `OPEN-QUESTIONS.md`, product risks in
   `RISKS.md`; this log names only the decision that the plan uses until the answer.
