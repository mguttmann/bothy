# Support

Bothy is a community project without commercial support. Maintainers answer as time
allows; GOVERNANCE.md describes how issues are triaged.

| You want to | Go to |
|---|---|
| Report a bug | an issue from the "Bug report" template |
| Propose a feature | an issue from the "Feature request" template; check docs/roadmap.md first |
| Report a vulnerability | SECURITY.md, never a public issue |
| Ask how to install or operate an instance | the operations guides under docs/operations/ |
| Connect your own agent or integration | docs/spec/09-agenten.md and docs/spec/11-erweiterungen.md |
| Contribute code or documentation | CONTRIBUTING.md |

The documentation is the first source of answers. Most planning documents are in German
with English identifiers; community files such as this one are in English.

Questions about a specific installation (its configuration, accounts or data) go to the
operator of that installation, not to this project.
