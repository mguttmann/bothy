# Tone check

1. Name the tone the draft has now in one short phrase (for example "formal and distant").
2. Name the tone the person wants; ask when it is unclear.
3. List up to five sentences that break the wanted tone, each with a rewrite.
4. End with the full draft in the wanted tone.
