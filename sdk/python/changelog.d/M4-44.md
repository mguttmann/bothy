### Added

- Project folders in the heartbeat (M4-44): `build_heartbeat(project_folders=...)` and
  `RuntimeStatus.project_folders` send the folder names a runner finds under its projects root
  (distinct, one segment of letters, digits, `.`, `_` and `-` that starts with a letter or digit,
  at most 255 characters); `None` leaves the member out, which the server reads as unchanged.
- Generated models and operation (M4-44): `Heartbeat.project_folders`, `ProjectFolder`,
  `ProjectFolderList` and `listAgentProjectFolders`.
