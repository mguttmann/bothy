### Added

- Fake-Agent ops for files and voice messages (M3-09): `read_file` (`downloadFile`, the reply
  holds the byte length, never the content) and `submit_transcript` (`If-Match` from the `ETag`
  of `getFile`); `context` lists the attachments of every element and whether a read file text
  or a transcript stands only inside a marked data block or in the trigger part (ADR 0054
  point 4). The FakeServer serves `getFile` and `submitTranscript` with the derived transcript
  `ETag` (`FakeServer.file_etag`).
