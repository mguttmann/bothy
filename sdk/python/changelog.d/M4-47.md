### Added

- Long answers stay one message (M4-47): `bothy_sdk.long_answers.send_long_message` sends an
  answer within `message_max_content_bytes` as it is and a longer one as one message with the head
  and the rest as one attachment `answer.txt` (`split_for_limit`, `upload_text`); when that upload
  fails the head goes out with a short note.

### Changed

- The FakeServer refuses a `createMessage` whose `content_md` is above
  `uploads.limits["message_max_content_bytes"]` with `400 validation_failed` `too_long`.
