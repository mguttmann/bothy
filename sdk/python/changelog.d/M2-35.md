### Added

- Run loop for the stop of the Claude Code runner (M2-35): the optional hook
  `AgentHandler.on_cancel(run, reason)` lets a handler stop its runtime and finish a started run
  itself (the adapter then cancels nothing and sends no `finishRun` of its own); a run that has
  not started is never started and is finished `cancelled` with the request's reason; a second
  request for the same run changes nothing; a follow-up of a run held but not yet started reaches
  `on_followup`.
- FakeServer parts for the runner's follow-up, stop and session scenarios (M2-35): follow-up rows
  that patches move forward (`followup_state`), follow-ups of Sam or with replaced token claims
  (`deliver_followup(author=..., claims=...)`), the route
  `getMessage` with `edit_message` and `hide_message`, `set_run_state`, `finishRun` of a run the
  server already ended answers its repeated final state, and `reportAgentSession` with a
  reference change and with `bind_failed` (a new current row, the old one ended with `rebind`).
- `RuntimeStatus.active_runs`: runs a handler runs outside the adapter's own loop (turns a runner
  adopted after a restart) join `active_runs` of the heartbeat (M2-35).

### Changed

- `bothy_sdk.runs.is_run_ended` also counts `401 unauthenticated` (the agent was disabled,
  09 2.1): the patcher stops and sets `RunHandle.cancelled`, and `finish` logs instead of
  raising (M2-35 note 6 e).
