### Added

- An adapter can hand its runs over at a restart instead of ending them (09 18.19.3):
  `Adapter.stop(hand_over=True)` sends no further heartbeat, cancels the run tasks with
  `Adapter.handing_over` set and finishes no run, and `AgentHandler.adopted_run` lets the next
  process take the follow-ups of a run it adopted (18.19.7). Nothing changes for an adapter that
  uses neither.
- The heartbeat accepts the capabilities `turn_handover` and `wakes` (`true` only, 09 18.19.1).
- The FakeServer answers `checkRunLaunch` (09 18.19.6): allowed while the run is `running`,
  `409 conflict` with `run_not_running` or a scripted refusal (`launch_refusal`).
