### Added

  `InterviewRequest` for `agent.interview_requested` and returns `InterviewReply.ask(...)`,
  `InterviewReply.propose(draft)` or `None`; the adapter sends the answer once with
  `answerAgentInterview` before `expires_at`. The generated core knows `interviewAgent`,
  `answerAgentInterview` and their models; the fake server sends interview requests.
