### Added

- `Client.rebind` and `RunHandle.bound`: a runtime callback on another task sends its requests
  with the run's newest invocation token (07 SR9).
- `OutboxEntry.created`: the message a reply created (ID, version, components), for a later
  `updateMessage` or `updateComponent`.
- FakeServer: `getMe`, `getThread`, `setThreadTitle`, `updateMessage`, `reportAgentSession` and
  `downloadFile` (one byte range), contexts with every trust mark, attachments and transcripts,
  Sam and Writer in the world, operator runs with `session_mode` and `agent_session`, the
  single-use click of 09 11.3, `Fault.problem` and `enable_costs`.

### Changed

- An allow list that cannot be loaded (09 17.7): `404` refuses the event with `adapter_error`
  and settles it; a network error, `429` or `5xx` leaves it unsettled (M2-33).
- `RunHandle.finish` repeats the end once without `costs` when the server refuses that member as
  not enabled.
- The lower bounds of `cryptography`, `PyJWT` and `websockets` are the versions of the pinned
  Hermes Agent environment, so the Hermes adapter installs without changing them.
